| ID | BAS-C12 |
| Experiment or failure mode | **Rejected `position` searched the previous board (1.10.1).** The 8.6.3a contract (2026-07-20) was reject-and-retain: a rejected `position` printed an `info string`, kept the previous board and kept answering. Its recorded residual risk was that a GUI ignoring the info string gets a legal move for the previous board. Measured on 1.10.1-rc2: `position startpos`, then `position fen 8/8/8/4k3/8/2BB4/4P3/4K3 w - - 0 1` (side not to move in check, correctly rejected), then `go depth 3` answers `bestmove b1c3`. That is a start-position move, while the side to move is the same as in the GUI's position. The legality check itself was already complete except for one geometric rule: the side to move in check from three or more pieces was accepted. |
| Disposition | **Policy flipped by maintainer decision 2026-09-27; bench unchanged at 14,978,465.** A rejected `position` (malformed header, bad FEN, illegal position, illegal move in the list) prints `info string CRITICAL ERROR: command ... was rejected; exiting.` and ends the process with `std::_Exit(1)`, the Stockfish/Rarog practice. `_Exit` rather than `exit`, because the UCI thread is still blocked on stdin. Parsing stays atomic in `Parameters::set_position`, which now returns acceptance; the policy lives in `Engine::handle_command` behind a test hook. The FEN check also rejects triple check (double check is still accepted). Alternatives weighed: keep 8.6.3a, or keep the board and answer `bestmove 0000`. Measured: exit status 1 about 1 ms after the bad command. Tests: eight rejected forms are each fatal with no `bestmove`; malformed `setoption` still survives; triple check rejected and double check accepted. Release CTest 12/12; ASan/UBSan on the six affected test binaries. |
| Conditional lesson / coverage | A retained board is only safe if nothing reads it. Here `go` did, and so did `send_bestmove`'s sanitizer, which fills in a legal move on whatever board it is handed. Survival was the wrong thing to optimise: a process that keeps answering in the wrong position fails silently, while one that exits fails loudly. Retry trigger: reopen only if a GUI in use is shown to send positions Basilisk rejects that are nonetheless legal, since those would now be fatal. |
