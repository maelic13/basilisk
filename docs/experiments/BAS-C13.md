| ID | BAS-C13 |
| Experiment or failure mode | **Tablebase PV lines restored the Stockfish way (1.10.1).** BAS-C11 removed Basilisk's tablebase PV extension because it ran unbounded before every search, for every winning root move. Stockfish (official master `0a215d6c`, 2026-09-22) keeps the feature but bounds it: `syzygy_extend_pv` runs when a PV is printed, keeps the searched line while it holds the tablebase result, extends to mate with minimal-DTZ moves, and under time management stops at `2 x MultiPV x elapsed >= Move Overhead`. Its last change, `19a02f44` (2026-08-25: complete under `nodestime`, share the budget across MultiPV lines), concerns features Basilisk lacks. A first port stopped short of mate on 2 of 4 real endgames. Fathom's `root_probe_dtz` ranks every clean win equally, so its "top rank" is any winning move and the line wandered into repetitions. |
| Disposition | **Implemented 2026-09-27; bench unchanged at 14,978,465.** `Syzygy::extend_pv` does Step 1 on Fathom's ranks, as Stockfish's Step 1 uses `rankDTZ = false`. Step 2 ranks by the per-move DTZ that `tb_probe_root` reports, Stockfish's `rankDTZ` formula, with the opponent-mobility tie-break. Under a clock or movetime only the final line is extended, once per move after the pool merge, and re-sent with the ponder move taken from it. Without a time limit every info line is extended, unbounded, as in Stockfish's analysis mode. Deliberate deviation: Stockfish also extends per-iteration lines under time management, but Basilisk prints a line at every depth, so that would pay the box up to ~30 times per move. The vendored Fathom's DTZ probing is thread-safe (double-checked table init; its "NOT thread safe" header note predates that). Measured: the four gate-loss positions now all extend to mate in analysis, the two longest in 45 and 43 plies. On six tablebase positions at the default Move Overhead 10 ms, the final line costs +1.0 to +5.6 ms per move over rc3, and three of the six complete to mate within the box. With Move Overhead 0 the cost is nothing; with 200 ms all six reach mate in 2-9 ms. Tests: extends to a legal mate within 25 plies on KQvK, which the wandering version fails; a queen-hanging PV move is cut and replaced; an expired box returns the line unchanged; the analysis PV is extended; at engine level the final line and ponder move are extended, and nothing is extended with Move Overhead 0. Release CTest 12/12; ASan/UBSan on the search, threading and ponder tests. Ponder stress 0 failures. A 200-game ponder-on smoke run vs 1.10.0 at `3+0.03` gave rc4 0 failures and 1.10.0 56; this is a smoke run, not a registered gate. A gate rerun on rc4 was stopped by the maintainer at 263 completed games: rc4 had 0 failures, 1.10.0 had 63 time losses. With the smoke run that is about 460 clean games for BAS-C13 (95% bound about 0.65% per game), while rc3's 1,005-game gate covers everything else. |
| Conditional lesson / coverage | The feature was never the defect; its placement and missing bound were. Removing it fixed the time losses and lost the display, while Stockfish's version keeps both. Second: a donor function is only portable together with its inputs. Stockfish's Step 2 depends on a `rankDTZ` ranking that the Fathom API Basilisk uses does not expose, and a straight transliteration compiles, runs and quietly fails to mate. |
