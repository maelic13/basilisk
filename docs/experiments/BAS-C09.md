| Experiment or failure mode | **Created pins and recapture promotions (15.0.c).** BAS-X29's remaining two SEE defects, ported from Rarog's `see-contract-v1`/`see-repair-v1`. Measured, both are narrower than their names suggest. **Created pins:** three of the four fixtures already PASS -- `see_pins` runs on the exchange occupancy with the mover already removed, so a pin opened by the mover's own departure is honoured. Only a pin opened mid-exchange by a LATER capturer fails, and only in `see_ge`; `see()` reaches the right answer because its X-ray truncation happens to stop first. **Promotion recaptures:** the kernel adds no promotion gain and leaves a pawn rather than a queen on the square. Each error is worth exactly (queen - pawn) = 800, so they **cancel exactly whenever the promoted piece is immediately recaptured**; the 800 survives only when the promoted piece stands. |
| Disposition | **CLOSED 2026-09-10 as a documented approximation, no engine source change; bench unchanged at 14,978,465.** Branch (2) of the leaf is triggered twice over. **Not reachable:** across 339,607 production `see_ge` calls (the 40 bench positions at depth 13, engine instrumented to recompute pins per ply and compare verdicts), created-pin verdict changes = **0** and promotion recaptures = **0**. On a deliberately adversarial random-walk corpus that drifts to sparse, pawn-heavy endgames -- 5,728,160 `see_ge` calls -- created-pin verdict changes are **172 (0.0030%)** and promotion recaptures **1,018 (0.018%)**, of which only the non-cancelling subset diverges. **Over cost:** the current-occupancy recapturer (recompute `see_pins` every ply) measures **+16.8% of the SEE column** in `tests/board_performance.cpp` (7,650,000 -> 6,547,556 captures; an independent micro-benchmark agreed at +17.8%), against the leaf's 10% ceiling. The promotion repair carries a second, separate cost not paid here: it invalidates `see_ge`'s `swap <= 0 -> return true` fast exit, which would have to be gated on last-rank targets -- 8.9% of production calls. Nine fixtures added to `tests/test_board.cpp`; the test oracle is now promotion-aware, and the three diverging cases pin BOTH the oracle truth and the kernel's approximate answer so the divergence cannot drift or be silently 'fixed'. |
| Conditional lesson / coverage | A defect's name is not its frequency. 'Created pins' sounded like one mechanism and is two: the mover-departure case was already correct and only the mid-exchange case fails, which is a rarer geometry by an order of magnitude. Check which fixtures already pass BEFORE pricing a repair. Second: two errors of equal magnitude and opposite sign are not two defects -- the promotion-recapture pair cancels exactly in the common continuation, so the reachable error is far smaller than either term. Third: correctness that no caller can reach is not worth 16.8% of a hot column, and the honest close is a pinned, documented approximation rather than a repair shipped because repairs feel safer (BAS-C05 doctrine). **Retry trigger:** reopen if production `see_ge` verdict changes exceed 0.1% of calls on the bench corpus after any selectivity or endgame-search change, or if an INCREMENTAL created-pin update (rather than a full per-ply `see_pins`) measures at or under 10% of the SEE column. |
